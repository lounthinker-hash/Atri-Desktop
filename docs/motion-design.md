# 桌面亚托莉的动作设计

桌面上的亚托莉只穿原作的**白色水手领服**（`d1`）。她可以换姿势、表情或站位，一整天都穿这套衣服。穿着约束也适用于听原声、自动活动、拖动及恢复待机。

## 先看动作是怎样接起来的

亚托莉正低头写日志，这时你从文档切到了音乐。她可以先写完眼前的一小笔，手停住，头略向一边倾听，再慢慢抬眼。如果你在这时把她拖走，写日志立即结束。落下时先稳住身体，稍后再决定继续写，还是看看新的位置。这段过程可以完全安静，游戏台词只在合适的停顿出现。

本文中的秒数是动作设计范围。**原作图层**提供原画中的体态、眉、眼、口、脸颊与脚部差分。下文的**近似演出**指使用这些画面，通过局部转动、重心移动和姿势切换表现动作。**需要补画**标出必须有新轮廓、新角度、道具或前后遮挡关系的细节。动作名也包括后续设计，收录在这里不等于已经有一段逐帧原画。

### 同一个角色的动作习惯

- **先看，再动。** 突然注意到东西时，眼睛和眉先有反应，头随后转，肩和躯干稍后跟上。犹豫时让眼神先停住，手慢半拍。
- **站稳才够得着。** 抬手、探身和迈步前，先把重心移向支撑腿。小跳落地时先屈身，头发和衣摆最后安定。长时间站立，偶尔换一下承重脚就足够。
- **让人看清她在做什么。** 阅读、写字和休息都可以低头，但阅读会停在一行末尾再回到起点，写字有短笔画和提笔，打盹时手指放松、抬头比低头慢。三者各用自己的节奏。
- **给她留出安静的时间。** 做完一件事可以继续看一会儿，得意后也可以自己收起笑容。平静站立时保留轻微呼吸与偶尔眨眼。背对用户时保留后脑和发尾的轮廓，眼口动作只用于能看见脸的姿势。

## 日常与交互

### 白裙实机中的跟随运动

待机和活动共用一套身体渲染。发根贴着头，左右各两束长发的中段和发梢分别积累速度。转头停住后，发梢能越过静止位置，再折返回来。眨眼只改变原作的眼部图层，长发接着上一帧运动。袖口贴近发尾的地方保留手指和袖口的支撑。

红领巾以领结为支点，肩上的蓝领边只在外侧弯曲。裙腰保持原画形状，左右下摆与中间褶面各有不同的响应。正面与背面的画法反映原画已有的遮挡，原作藏在袖后、发下的布料不会凭空露出来。

右键选择「试演身体动作」中的「侧身回望」，可以看转头后的收势。写日志时，下方手指托住书脊，上方手指压在封面上。打开或合起封面时，腕、袖缘和书共用握点。公开版已加入持书、开合、夹页和执笔手形，仍在调整动作切换时手掌与书脊的遮挡。角色在地面螃蟹旁起跳时，螃蟹的落脚点和大小保持稳定。

### 1. 启动、睡醒和初次见面

**动作串**　`wake → stretch → greet → bow → settle`。

登录后一出现，双脚先站稳。眼睛由闭到半睁，再睁开，眉梢轻抬。她抬头看向用户，肩打开，手臂伸展，到顶稍停，再把手收回来。问好时手抬到肩边，接一个很短的点头或小鞠躬，起身后才露出笑。白天重新显示窗口时只看过来点一下头，连续唤回时略去整套晨起动作。

**画面**　睁眼、闭眼、笑和举臂姿态可用原作画面，伸展与鞠躬可做近似演出。挥手时的手腕翻转、手指张合，需要单独画手部差分。

### 2. 被点到、回应和介绍东西

**动作串**　`glance → turn → greet / point → nod`。

单击时，先中止她正在做的事情。眼神回到用户，眉和嘴角随选中的原声变化，头稍后转正。说话时脚下保持稳定，手可以顺着语气抬一下，句尾闭口、停一拍，再放手。介绍物品时先看物品，接着侧身抬手，再回头看用户是否注意到。这个指向动作只在有明确目标时使用。

**画面**　可使用原作的眉眼口与手臂姿势，按录音响度驱动已有口形。精确指向桌面某个位置还需伸出食指的手形及对应的侧臂原画。

### 3. 留意屏幕、好奇和探看

**动作串**　`glance → listen → peek / lean → inspect → settle`。

确认前台内容发生变化后，她先侧目，再转头。近旁像有东西吸引她时，眉抬起一点，一只脚留作支撑，上身探出去，手自然靠近身侧。看清后停两三秒，再决定走近还是退回。没有匹配的屏幕线索时，她可以继续自己的日常。同一画面持续显示期间，留在原处看一会儿即可。

**画面**　原作表情配合身体前倾、缩回和侧转可以传达好奇。精确眼球追踪需要独立瞳孔和眼白素材。桌面识别得到的是活动类别，演出只表现她留意到了这类活动。

### 4. 自己在桌面上走动

**动作串**　`look_around → turn → step / tiptoe → inspect → walk_back`。

选好方向后先侧头，再带肩，重心从一只脚移到另一只脚。普通走动分四五个小步，跨步时躯干略有起伏，停步后双脚重新站稳。蹑手蹑脚时迈得更短，头先探出去，收脚也更轻。回程先回望原来的位置，转向，再走；不一边直视前方一边倒滑回去。

**画面**　原作正、背姿态与整身位移可近似表现换位，发梢和衣摆可随步伐稍迟回落。要看见脚尖离地、鞋底翻转、两腿前后交替，以及从正面连续转到背面，需要侧身、分腿和走路中间帧。

### 5. 安静待机与陪伴

**动作串**　`settle → wait / watch → glance → settle`。

无人操作时，两只手自然垂下，眉眼放松，嘴闭合，肩随呼吸轻轻起落。偶尔重心偏到一侧，视线在附近停一会儿。与用户一起看视频时，可以先挪半步，朝同一方向看，停留时间比普通待机更长。用户忙碌、未点击或关闭自动开口时，这段陪伴可以始终没有字幕和声音。

**画面**　已有立绘足以近似表现。呼吸主要落在肩胸，脚底的接地点保持安定。若想让她坐到屏幕边缘、托着脸看，需要坐姿、弯腿、托腮手和相互遮挡的新画面。

### 6. 上课、复习和思考难题

**动作串**　`read → turn_page → read → nod`；理科题使用 `inspect → read → count → think`。

识别到教材、公式，或她自己开始学习时，先把视线落到身前较低处，头跟着低下来。阅读时头轻轻横移，到行尾略停，再移回。翻页的手先抬起，手肘跟进，另一侧肩保持稳定；下一页摊好，视线才重新落下。心算时眉靠拢，指尖可以分拍计数。弄懂后点一次头，脚始终站在同一处。她理科成绩好，也会耐心给同学讲题，见原作 `b201` 第 93 段、`b302` 第 147 段。

**画面**　面部专注、低头、思考和点头可近似演出。让书真正出现在手里，需要书封、书页、夹住书脊的手、翻页手和页片弯曲的阶段图。逐个伸指计数也需手指差分。

### 7. 写日志、停笔和重读

**动作串**　`turn_page → write → think → write → settle`。

看到用户写作，或到了整理记录的时间，她先低头看向连衣裙口袋，肩和手才往下。记日志时，非执笔侧微微固定，执笔侧短促移动几次，提笔，停顿，再另起一行。回想事情时先停手，抬眼，眉稍松，再低头续写。完成时目光回到开头重读，合上本子，才收好手。原作中她把日志收在连衣裙内侧的口袋，见 `b201` 第 343 段。

**画面**　低头、短促腕部节奏和思考时的眼神可以近似表现。把手伸进口袋、握笔、另一手压住日志、页面出现墨迹等细节，需要笔、日志、不同手形以及衣服遮住手部的图层。日志页面可以使用项目内的虚构记录，画面不呈现用户屏幕上的文字。

### 8. 遇到错误、再试一次和庆祝成功

**动作串**　明确失败时 `peek → think → beckon → wait`。明确成功时 `surprise → cheer → proud`。

看到调试失败，她先望过来，眉尖稍抬，歪一下头，停一拍才尝试招手。身体留在一侧等待，让用户继续操作。之后若看到验证通过，先睁大眼，再抬头举起手，胸口挺起，笑容最后出现。平常自称“高性能”时，更适合小幅挺胸、下巴抬高一点；真正庆祝时才明显举臂。普通代码编辑和明确的失败提示分别处理。

**画面**　惊讶、得意的眉眼与举臂姿态可用原作差分，等待和挺胸可做近似演出。招手时掌心的朝向，以及双手拍到一起再分开的动作，需要补画。看见失败后安静陪伴也是完整反应。

### 9. 听音乐、打拍子和哼歌

**动作串**　`listen → sway → hum → settle`。

她先停下手里的事，一边耳朵向声音的方向倾过去，眼睛半合。肩和躯干随后轻轻摆动，膝盖跟着放松，双脚仍踩在原处。哼到句尾先闭口，身体的摆动再慢下来。原作里她能从犹疑的轻声，慢慢唱出记忆里的旋律，见 `b203` 第 295–321 段。

**画面**　可用原作眼口与侧倾近似演出。屏幕只能显示“正在使用音乐应用”时，以她自己的节奏轻摆。要与正在播放的音乐逐拍同步，还需要真实节拍输入；要明确表现唱某一首歌，则需要相应的原作音轨。

### 10. 做饭、尝味和终于做对了

**动作串**　`read → knead → stir → taste → nod / proud`。

她先看一眼食谱，停一下再动手。揉肉时重心向前，两只手向下按，再放松，来两三次便停。搅拌时一侧肩相对稳定，另一只手画小圈。尝味前先停下搅拌，头向拿勺的手靠近，闭口想一会儿，满意时才轻轻点头。她从料理部成员那里学了揉肉、调味与掌握火候，见 `b204` 第 355–365 段。

**画面**　现有身体能近似表现按压、搅拌的方向和尝味时的神态。有可见的汉堡肉、碗、勺、灶台才构成完整做饭画面。握勺、抵住碗沿、把食物送到嘴边，都需要配套手形和道具遮挡。

### 11. 在海边找螃蟹、远望灯光

**动作串**　发现东西时 `look_around → tiptoe → inspect → hop`。看远处时 `turn → watch → think`。

她先左右张望，注意到动静后眼睛定住，头跟着转，走两步，才低身细看。欣喜时短促地抬起手，小跳一次，落稳后继续盯着发现物。远望灯光的节奏不同，头转过去后保留一段静止，脸上的表情慢慢舒展开。她潜水回收树脂却先捧出螃蟹，见 `b121` 第 150–179 段。海边活动仍穿桌面的白色日常服。

**画面**　可近似表现寻找、移步、惊喜和远望。真的举起螃蟹，需要螃蟹、托住它的双手及两者前后相叠的轮廓。没有这套素材时，她可以只停步低头看。

### 12. 犯困、小憩和被叫醒

**动作串**　`step → yawn → doze → rest`。醒来用 `wake → glance → stretch`。

夜深或长时间空闲时，她先挪到舒服的位置。打哈欠先放松肩膀，再半闭眼、张口，合口后才让头垂下。打盹时头偶尔下坠一点，短暂抬起，之后进入更长的休息，手和脚都安定。轻唤时眼先半睁，头慢慢抬起，让她有一瞬看清是谁。处于休息状态时不必反复播晚安。

**画面**　睁闭眼、张合口、垂头与站着打盹可近似演出。用手遮住嘴、趴在桌上、躺在床上、枕着手臂等需要专门原画及支撑物。

### 13. 被拖走、放下和重新站稳

**动作串**　`surprise → drag → land → settle`。

在角色身上按住并越过拖动阈值时，当前活动立即交出控制。她先睁大眼，头朝移动方向回望，肩、发梢和袖口稍滞后。拖动中保持与指针同步，快速换向只留一次短暂的重心变化。松手时脚先落稳，膝和躯干轻轻下沉，头发随后回落，她再抬眼看用户。一次短单击直接走单击回应，避免先演一遍被拎起。

**画面**　拖动、落地减速、表情与衣摆回落可近似表现。双足真正悬空、衣领被提起的褶皱，以及手要抓住某个位置，都要新增专用姿势。

### 14. 害羞、拒绝和拉开一点距离

**动作串**　`shy → glance → turn_away`，或 `refuse → walk_back → settle`。

在适合的原作台词或重复逗弄的设计情境里，她先移开视线，眉收紧一点，手更靠近身侧，再侧过肩。害羞时可以稍后偷看回来；明确拒绝时保持距离、轻轻摇头，停住一会儿。手腕和肩放松后，再接其他行为。普通拖动始终把选定的新位置作为落点，角色的情绪动作不会把窗口拖回去。

**画面**　现有害羞的眉眼、脸颊和背面姿势可以近似使用。完整的回头侧脸、双手护住身体、抱臂或掌心朝外说“停”，需要对应手臂和侧面原画。重复逗弄属于可选触发设计。

### 15. 屏幕边缘、窗口遮挡和环境变化

**动作串**　`glance → wait → turn / walk_back`。

主动走动接近可用桌面边缘时，眼先看向边缘，脚收住，上身略向后平衡，转身后再选新方向。显示器布局或分辨率变化后，先让整个人回到可见区域，再恢复呼吸和待机。菜单打开期间暂停自主移动，方便点击。屏幕感知未确认、关掉或暂不可用时，她仍可以读书、休息或做自己的事。

**画面**　这些情况主要依靠窗口定位、步态近似和停顿。扶住显示器边框、趴在窗口顶边或探出半个身体，需要手掌接触边缘的素材和针对窗口边缘的裁切。

### 16. 暂停、告别和退出

**动作串**　短暂停用 `settle`，主动示意告别可用 `greet → bow → settle`。

暂停自动活动时，手和躯干马上交还控制，脚保持在当前位置。若设计独立的告别动作，可以让她看过来、抬手，收手后轻轻鞠躬，再抬头。退出命令应及时结束常驻；用户已选退出时不必等她说完一段话。下一次出现从自然站姿进入新的活动。

**画面**　停稳、小幅鞠躬与收势可近似表现。完整摆手告别、走远到消失的背面步态，分别需要手腕和背面走路差分。

## 同一场面怎样读出不同情绪

| 情绪与触发 | 眼、眉、头和手怎样接上身体 | 现有素材的表现范围 |
|---|---|---|
| 开心。对应的原声在道谢，或一个小实验做成了 | 先睁眼看向对方，眉渐松，嘴角抬起；肩稍提、上身往前迎，手抬起后轻快落回。小事只笑一下，值得庆祝时才接 `cheer` | 原作笑脸、闭眼笑和举臂姿态能支持近似；拍手需要手掌相合的画面 |
| 得意。夸她高性能，或她主动展示成果 | 先看一眼用户的反应，再抬下巴，胸口向前，肩打开，双脚站稳；停上半拍才移开目光。她说惯常的“高性能”时可以使用 `proud` | 眉眼和嘴形可用原作；叉腰时手掌与腰侧贴合的细节取决于选用的原画 |
| 感激。回应帮助或熟悉的朋友 | 眼神先落回对方，眉松，手靠近胸前，肩带头轻轻下倾；起身后停住目光再收手。可接 `bow` | 小鞠躬能做近似；双手合在胸前需要成套手形 |
| 担心、安慰。明确看到失败，或播放相关原作片段 | 眉心收拢，先侧头倾听，再靠近半步，把手抬到一个能停下的位置。等对方回应时姿态放松、脚不再前移。可接 `listen` 或 `wait` | 近似演出可表现靠近陪伴；摸头、握手或递毛巾需要手部接触画面。原作中她曾给受幻肢痛折磨的夏生擦汗，见 `b103` 第 64–79 段 |
| 委屈或生气。适合她听到“萝卜子”等原作桥段时 | 目光先钉住，眉靠拢，嘴收紧，随后把重心移到一侧，头转开。下一拍可以回望，或退开一步，等情绪平复 | 原作不悦的表情与 `refuse`、`turn_away` 能近似表现；握拳、抱臂要有对应手臂素材 |
| 悲伤或思念。用户主动选择有关回忆的原作内容时 | 活动先慢下来，手停住，目光下移，肩略向内收，呼吸和抬头之间留一个比平时长的停顿。再次抬眼后，才接下一句或安静收势 | 可用沉静的原作表情和低头姿态。泪珠沿脸颊移动需要单独的泪水素材；日常待机不随机重演沉重剧情 |

## 原画扩充时，先补哪些部位

| 优先补充的素材 | 能直接改善的动作 | 绘制时最值得保留的细节 |
